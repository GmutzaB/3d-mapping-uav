# Simulation

The working airflow/thrust demonstration remains at the repository root to preserve
existing commands and VS Code launch configurations:

- `../simulation.py`
- `../compare_grids.py`
- `../test_simulation.py`

It models a 2D flow slice and empirical thrust, not full aircraft dynamics or navigation.

Add future vehicle models, worlds and scenarios here for ArduPilot software-in-the-loop
and Gazebo. No SITL environment or validated aircraft model is included yet.

Reference: [ArduPilot with Gazebo](https://ardupilot.org/dev/docs/sitl-with-gazebo.html).
